# NCL
NCL (Nzzhxl Coding Language), is a custom made programming language written in Python.\
It's going to be an interpreter at first. After a while, it's going to become a usable programming language.

## How to Use Interpreter: 
**Command Order:** ```Function | Arguments``` (Spaces in Arguments Don't Matter) 
- Case-insensitive Syntax & Arguments (**All Input is Converted to Lowercase**)

### Functions:
- About - Information About NCL.
- Math - Evaluates Arithmetic Expressions. Example: math 2**2 OR math 2/2
- Help - Prints a Simple Help Message.
- Say - Prints the Argument. Use Quotes/Double Quotes to Print String or It Might Print the Value of a Variable.
- Del - Delete a Variable. Example: del abc
- Var - Create a Variable and Show All the Variables. Example: var abc=123 AND var
- If - Evaluates Comparison, Returns Boolean. Example: if abc=123 OR if 1+2=3
