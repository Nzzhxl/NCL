# NCL
NCL (Nzzhxl Coding Language), is a custom made programming language written in Python.\
It's going to be an interpreter at first. After a while, it's going to become a usable programming language.

## How to Use Interpreter: 
**Command Order:** ```Function | Arguments``` (Spaces in Arguments Don't Matter) 
- Case-insensitive Syntax & Arguments (**All Input is Converted to Lowercase**)
- Semicolons (;) to Separate Multiple Commands in One Line (**Recommended to Use Space After a Semicolon**)

### Functions (Simplified):
- About - Information About NCL.
- Math - Evaluates Arithmetic Expressions.
- Help - Prints a Simple Help Message.
- Say - Prints the Argument.
- Del - Delete a Variable or All Variables.
- Var - Create a Variable. Example: var abc=123 AND var
- If - Evaluates Comparison.

### Functions (Extended):
- Say - Prints the Argument. Use Quotes/Double Quotes to Print String or It Might Print the Value of a Variable.
**Example**: say abc hello world OR say "abc hello world"

- Del - Delete a Variable or All Variables.\
**Example**: del abc OR del "all"
  
- Var - Create a Variable and Show All the Variables. If Double Quotes (“) Are Used at the Start/End of a Variable’s Name, It Will Get Removed.\
**Example**: var abc=123 AND var
  
- If - Evaluates Comparison, Returns Boolean.\
**Example**: if abc=123 OR if 1+2=3
